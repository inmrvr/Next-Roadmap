Полная дорожная карта SynSaveinstance Next

Это уже не карта «до M5». Здесь отражён исходный проектный plan целиком: от архитектурного аудита до Terrain, пользовательского workflow, небольших live-сцен, проверки на реальных участках карты и финального full-map release. M8 — конец текущего утверждённого master-plan, а не утверждение, что продукт никогда больше не будет развиваться.

F01

Q01 — обязательный review каждого крупного milestone

Milestone не считается закрытым только потому, что код работает на happy path.

  1. Architecture Review — owners, API, dependencies, no hidden global state.
  2. Correctness Review — invariants/RTM, UNKNOWN сохраняется.
  3. Failure-Mode Review — crash, cancel, corruption, late callbacks, limits.
  4. Performance + Memory Review — measured baseline и bottlenecks.
  5. Duplication / Dead-Code Review — убрать дубли и obsolete branches.
  6. Logging Review — bounded volume, redaction, I/O overhead.
  7. Testability Review — независимые oracles, deterministic ports/fixtures.
  8. Refactoring Pass — упростить найденные нарушения.
  9. Optimization Pass — только измеренные bottlenecks.
  10. Final milestone report — что доказано, что OPEN, exact source/results hashes.
